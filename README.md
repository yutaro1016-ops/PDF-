# PDFページ検索

複数のPDFをブラウザーで開き、それぞれの実際のページ数を自動取得して、本文を一括検索する静的Webアプリです。

## 使い方

1. 「PDFを追加」から複数のファイルを選択するか、プレビュー領域にドラッグします。あとから追加もできます。
2. PDFごとのページ数とプレビューが表示され、読み取れた本文をすべてのPDFから検索できます。PDF一覧から表示を切り替えたり、個別に削除したりできます。
3. 検索結果にPDF名とページ番号が表示されます。押すとそのPDFの該当ページへ移動します。ページ番号の直接入力や前後移動、拡大縮小もできます。
4. 表示したページの文字をドラッグして選択し、通常のコピー操作で貼り付けられます。

PDFは端末内で処理し、サーバーには送信しません。文字情報のないスキャン画像PDFにはOCRを行わないため、その画像内の文字は検索・コピーできません。暗号化されたPDFのパスワード入力には対応していません。

## 公開

`index.html` を含むディレクトリを静的ホスティングに配置するだけで使えます。GitHub Pagesでは、このディレクトリのファイルをリポジトリのルートに置き、Settings → Pages で `Deploy from a branch` と `main / (root)` を選択します。利用者は公開URLから自分のPDFを開けます。

PDF.js 5.6.205 のブラウザー向けビルドと互換性を高めた legacy ビルドを `vendor/` に同梱しています。アプリは legacy ビルドを使用します。ライセンスは `vendor/pdfjs-LICENSE.txt` を参照してください。
