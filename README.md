# PDFページ検索

[公開アプリを使う](https://pdf-page-finder.yutaro1016.chatgpt.site/)

PDFをブラウザーで開き、実際のページ数を自動取得して、本文検索の結果から該当ページへ移動する静的Webアプリです。

## 使い方

1. 「PDFを開く」からファイルを選択するか、プレビュー領域にドラッグします。
2. ページ数とプレビューが表示され、文字の読み取りが完了すると検索できます。
3. 検索結果を押すと該当ページに移動します。ページ番号の直接入力や前後移動、拡大縮小もできます。
4. 表示したページの文字をドラッグして選択し、通常のコピー操作で貼り付けられます。

PDFは端末内で処理し、サーバーには送信しません。文字情報のないスキャン画像PDFにはOCRを行わないため、その画像内の文字は検索・コピーできません。暗号化されたPDFのパスワード入力には対応していません。

## 公開

`index.html` を含むディレクトリを静的ホスティングに配置するだけで使えます。GitHub Pagesでは、このディレクトリのファイルをリポジトリのルートに置き、Settings → Pages で `Deploy from a branch` と `main / (root)` を選択します。利用者は公開URLから自分のPDFを開けます。

PDF.js 5.6.205 のブラウザー向けビルドを `vendor/` に同梱しています。ライセンスは `vendor/pdfjs-LICENSE.txt` を参照してください。
