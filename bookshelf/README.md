# PDF本棚

ログインした利用者ごとにPDFを保存し、複数端末からタイトル・本文の用語を検索できるWebアプリです。

- PDFを複数選択して本棚に登録し、タイトルを変更・検索できます。
- 本文をページごとに検索し、結果から該当するPDFとページを開けます。
- ページ数をPDFから自動取得し、表示中の文字は選択・コピーできます。
- PDFと検索用の文字はCloudflare R2/D1に保存します。ログインした本人のみが取得できます。
- PDFは50MB以下。スキャン画像PDFの文字にはOCRを行いません。パスワード付きPDFには対応しません。

初回はChatGPTログインが必要です。別端末でも同じChatGPTアカウントでログインすると同じ本棚が表示されます。ブラウザーでファイルを読み込む際に文字索引を作成するため、途中で閉じた場合は本棚の「文字を再取得」から再開できます。
