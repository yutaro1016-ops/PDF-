# PDF本棚

ログインした利用者ごとにPDFを保存し、複数端末からタイトル・本文の用語を検索できるWebアプリです。

- PDFを複数選択して本棚に登録し、タイトルを変更・検索できます。
- 本棚のタイトルはスクロールしながら確認できます。本文検索は全PDFまたは選択した複数の本を対象にでき、結果から該当するPDFとページを開けます。
- ページ数をPDFから自動取得し、表示中の文字は選択・コピーできます。
- PDFと検索用の文字はCloudflare R2/D1に保存します。ログインした本人のみが取得できます。
- PDFは1GB以下。大きいPDFは8MBずつ保存し、閲覧時は必要な部分を読み込みます。スキャン画像PDFの文字にはOCRを行いません。パスワード付きPDFには対応しません。

初回はChatGPTログインが必要です。別端末でも同じChatGPTアカウントでログインすると同じ本棚が表示されます。保存後にブラウザーで文字索引を作成します。途中で閉じた場合や端末のメモリー不足で失敗した場合でもPDFは保存され、本棚の「文字を再取得」から再開できます。

販売前整備(version17): データ管理で容量目安・設定出力・対応環境のフォルダーバックアップ・既存本設定の復元を提供します。5GBは計画値で強制制限なし。課金/試用期限/退会自動処理/自動監視は未導入です。

監査と未確認項目: [販売前監査](docs/sales-readiness-audit.md) / [運用・移行案](docs/operations-and-migration.md)。書き出しにはPDF/文字索引が含まれるので非公開に保管してください。`scripts/restore-backup.py` は既存本番に書き込まず新規ローカル検証領域を作成します。

version18: 原子的な5GB容量予約と退会ジョブを追加（両方とも本番では無効）。フォルダー保存は中断/冊単位再開/元データ変更検出に対応。各本の検索索引も個別保存できます。通常/32MB超の自作PDFによるローカル統合試験あり。実端末/本番別利用者/1GB/本番復旧は未確認。

GitHubからの再現: Node22.13以上・Python3で `npm run install:ci`、`python3 scripts/prepare-pdf-vendor.py`、`npm run build`。PDF.jsは既存と同じ5.6.205の固定tarballから200資産をハッシュ照合して再現。公開時は同じSitesプロジェクトへ保存・デプロイします。GitHub→Sites自動公開は未設定。 `.env.example` は販売前機能をOFFにした設定例です。
