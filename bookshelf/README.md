# PDF本棚

公開アプリ: https://pdf-page-finder.yutaro1016.chatgpt.site/shelf

このディレクトリは公開 Sites プロジェクトの主要ソースの GitHub ミラーです。公開版 15 の Sites ソースコミットは `de9b834c9faca020301fa6b3ff527e19ec3a2312`、Sites プロジェクト ID は `appgprj_6abb0a1c108c8191a976513dd82174aa` です。GitHub の push だけでは公開版は変わりません。公開時は Sites のソースリポジトリへ同じ変更を反映し、保存済み版をデプロイしてください。

- PDF 本体は利用者ごとの R2、メタデータとページ本文は D1 に保存します。GitHub へ登録済み PDF や利用者データは置きません。
- PDF ID と R2 キーは変更せず、追加の D1 移行で本棚と装飾情報を管理します。所属なしの既存 PDF は未分類に表示します。
- 1GB 以下の PDF を扱い、8MB 超は分割登録します。PDF.js は必要な範囲を取得し、本文索引はページ単位で保存します。
- 本棚の作成・設定・削除、PDF の移動・順序・色・タグ・表紙設定、全冊または複数冊での本文検索を備えます。画像 PDF の OCR はありません。
- `python3 tests/migration_test.py` と `node --check public/app.js` が GitHub Actions でも実行されます。

Sites のソースリポジトリが完全なビルドソースです。この GitHub ミラーには PDF.js 配布物や一部のビルド補助ファイルが含まれていないため、単独でのデプロイにはそれらの同期が必要です。公開環境への自動デプロイは設定されていません。

表紙の取得状況と再試行を表示します。PDF 第1ページから生成した小さな JPEG は利用者別 R2 にキャッシュされ、PDF 削除時に一緒に削除されます。`node tests/thumbnail_test.mjs` は同時生成上限、重複取得防止、キャッシュ利用、失敗時の再試行表示を検証します。利用者の端末で報告された不表示そのものは未再現です。

## 本・本棚の共有

本を選択して「共有」、または対象本棚の「本棚を共有」から共有リンクを作成します。ログイン済みの受取人は、既存の本棚へ本を追加するか、新しい本棚ごと追加できます。共有対象はリンク作成時の本の集合です。期限は1日・7日・30日・期限なし、画面上部の「共有」で停止できます。停止しても追加済みの独立コピーは削除されません。

PDFはR2内で8MBずつコピーし、新しいPDF IDを発行します。表紙設定・タグ・デザインとページ本文索引もコピーします。未完了のコピーは一覧・検索に出さず、進捗をD1へ保存します。取り込み中は画面を開いておく必要があり、閉じた後は同じリンクまたは共有管理画面から再開・中止できます。共有元で削除された本は追加できません。同じリンクから追加済みの本は重複追加しません。1リンクにつき1000冊までです。

追加テーブルは shares/share_books/import_jobs/import_items。既存PDF・ページ索引・本棚は書き換えません。`node tests/sharing_test.mjs` は実SQLiteとR2の模擬ストレージを使用し、別利用者の権限、8MB超の分割コピー、再開、本文検索、Range閲覧、期限切れ・共有停止、未完了コピーの清掃を検証します。公開環境で実利用者2アカウントによる操作、iPhone、1GB PDF実転送は未確認です。
