- 本番利用者の資料を使わず、使用許可のある専用テストアカウントA/Bを用意する。異なるブラウザープロファイルでログインし、A/Bを混同しない。作成・招待は本人が行う。こちらから招待は送信しない。

- 自作PDFを2冊用意し、異なるタイトルと本文中の固有検索語を含める。1冊は画像入り第1ページとする。登録前のSHA256とバイト数を手元で記録する。患者情報・配布権のない教科書は使わない。
- この実行環境ではSitesの指定ブラウザー操作ツールと許可された別アカウントを確認できていない。認証回避・未承認のアカウント使用は行っていない。公式ブラウザー操作環境を利用可能にするか、以下をご自身で実施し結果を提示する。

## 大容量試験は別途準備後
利用枠・費用・専用アカウントの許可を確認してから、32→128→512MiB→最大1GiBへ段階的に進む。各段階で登録/閲覧/索引/検索と中断・再開、本体ハッシュを照合する。画像主体/多数ページPDFを含め、端末メモリと所要時間も記録。ローカル約1GiB・2,000ページ・画像24ページの合格を本番合格に転記しない。
